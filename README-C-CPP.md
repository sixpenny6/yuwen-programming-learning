## 安装与使用

运行对应安装包：

- `releases/像学语文一样学 C Setup 1.3.1.exe`
- `releases/像学语文一样学 C++ Setup 1.3.1.exe`

按向导安装即可，无需另装编译器。两款软件独立安装、独立卸载，可与原 Python 软件共存。

从左侧目录进入阶段，使用“上一页 / 下一页”翻页。讲解页按“下一步”阅读；演示页依次查看“识字分析、语境填充、代码用途”。第152页为全能编程实验室，可以修改、生成和真实编译运行代码。程序需要输入时，在运行面板逐次填写并按回车发送；“停止运行”结束当前任务。编辑内容需要保留时，请自行复制另存为 `.c` 或 `.cpp`。

课程、测验和编译运行可离线使用；AI 助教、生成和释义需要联网。AI 使用软件配置的 DeepSeek 账号额度。

保留1.2.4的小窗口修复：代码按词块换行，较长内容在正文区滚动，页脚仍可操作；帮助按钮在顶部预留位置，小窗口可用菜单按钮打开目录。

1.3.1修复彩色代码词块缺少单词分隔的问题：测验、讲解和演示统一显示`std::string name`、`const char`、`else if`等必要空格。测验代码框使用可用宽度，避免新增空格把短声明挤断。保留原有空白、字符串原文和`::`、`++`等符号；不改课程内容、点读原文和录音，Python版不变。

1.3.0在原153页组成、顺序和教学步骤内，选择更能体现各语言用法的例子，并同步讲解、三色代码、用途演示、测验和录音：

| 教学任务 | C的写法 | C++的写法 |
| --- | --- | --- |
| 通过函数处理数据 | 指针参数交换变量，取地址与解引用 | 用`int&`引用参数给原成绩加5分 |
| 组织资料与行为 | `struct`及指定字段初始化 | 简单购物车类、学生对象与构造函数 |
| 处理成绩数据 | 固定数组、下标、`sizeof`计数 | `vector`添加元素、范围`for`遍历 |
| 处理文字 | 字符数组、单个字符修改、`puts` | `std::string`构造、拼接与`empty()` |
| 检查输入 | 检查`scanf`读取结果 | 检查`cin`输入流状态 |
| 读写记事本 | `FILE*`、基本读写及关闭 | `ofstream/ifstream`读写文字 |

这些写法按学习进度分布在组词、造句和写作中，每例只突出一个新知识点。例子面向初学者，不讲手动申请/释放动态内存、继承/虚函数、迭代器或泛型算法等进阶内容。文件示例在同一次运行中自写自读；实验室每次运行使用独立临时目录，不提供跨运行保存文件的项目管理。

三版使用晓晓（`zh-CN-XiaoxiaoNeural`），包括每版47道测验的全部143种答案反馈。新增或修改的C/C++朗读原文补做同声线录音，未改原文复用已有录音；合成保持正常语速`+0%`，播放速度1.0。录音随包提供，可离线播放；切换页面或点击另一段朗读会停止上一段，录音异常会明确失败，不切换其他系统声音。

朗读入口仍与原版一致：点击总览卡片、代码token、造句页的代码行或提示喇叭，以及选择测验答案后的反馈。组词、写作的“下一步”继续用于阅读步骤，没有新增自动朗读或朗读按钮。课程组成、顺序与153页数量不变；无需安装语音模型、GPU环境或配置付费TTS Key。
